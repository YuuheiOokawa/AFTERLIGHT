# AFTERLIGHT ― 未明の継承者
設計版 1.0 / 2026-10-13 / オリジナル縦持ちスマートフォンRPG

## 提供範囲
本パッケージは企画・実装設計、生成AI画像、操作可能なHTMLプロトタイプ、API契約、PostgreSQL DDL、コンテンツマスタと受入基準を提供する。ストア配布用APK/IPA、稼働サーバー、全本編シナリオ本文、500時間分の実装済みゲームを含む完成製品ではない。本編40時間・エンド500時間は制作目標と計測仮説であり、プレイテストで検証する。

## 一行企画
「実現しなかった未来」を救い、その未来を誰に渡すかを選ぶ、タップ連携型の継承RPG。

## 世界の仕組み
この世界では、誰かが選ばなかった未来が捨てられずに地層になる。告白しなかった街。発明されなかった電車。戦争を回避したため存在しなかった英雄。現実の下には膨大な『未明層』が積もり、そこにも生活がある。
未明層の住民は偽物ではない。現在と同じ強度の意思を持つ。ただし地上の選択が確定するたび、対応する未明層は崩壊する。救出された住民を召喚するのではなく、『地上で実現できる可能性』として継承するのが編成システムである。
主人公は未来を予言できない地図師。通常の地図師が「行ける場所」を描くのに対し、主人公だけは「行かなかった場所」を歩ける。大敵は世界を壊す魔王ではなく、全員を苦しめないよう全選択を凍結するために造られた公共システム『安寧局』。安寧局の善意も、主人公の救出も、別の誰かの生存空間を圧迫する。
最後に明かされるのは、地上もまた選ばれなかった未来の一つだったという事実。最終目的は一つの正史を奪い合うことから、異なる未来が互いを消さず接続できる世界を作ることへ変わる。
既存作品との重複が一切ないことは保証しない。物語の独自性は『未来の廃棄物に住む人々』『救出が別の未来を侵食する倫理』『地図と編成が同じ継承行為』の組み合わせで作る。

## 体験の柱
1. 指で5人を順番にタップすると攻撃がつながる。複雑なコマンド階層はない。
2. 高レアを引く瞬間に音、光、門の変形、人物の声が段階的に重なる。
3. 同じ仲間の「別の人生」を育て、戦闘役割を切り替える。低レアも固有役割を持つ。
4. 周回の長さでなく、パーティー・武具・敵予告への回答を変えることで長く遊べる。
5. ギルドは競争を強制せず、異なる未来の地図を共同でつなぐ場所になる。

## 本編の終わり
主人公は『全部を救う一本の未来』を諦める。代わりに複数の地上を接続し、救われた人々にその維持を託す。最終バトルはシステムの破壊ではなく、5人が別々の未来を支えながら門を開く共同作業。最終選択はエピローグ、拠点風景、別人生クエストに反映するが戦闘能力格差は生まない。
