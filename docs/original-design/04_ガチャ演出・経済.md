# 召喚「未明の門」— 最優先体験

## 概念
仲間は石から出現しない。プレイヤーが選ばれなかった人生の封書を開き、その人物がいた景色ごと門の向こうから接続する。背景の星座、門の輪、人物の台詞の三層で期待を作る。

## 抽選と演出を分離
課金ガチャはサーバーで抽選を確定・台帳更新してから演出を返す。画面へのタップ時刻や演出途中の操作でレア度は変わらない。結果はdraw_idに紐づく不変レコード。再接続・スキップ・アプリ終了でも同じ結果を再表示する。結果を見せる前の演出情報には最大レア度と保証フラグを含め、クライアントはそれに従う。

## 確率案（未課金の設計値）
R 75% / SR 22% / SSR 3%。10連の10枠目はSR以上保証、SR97% / SSR3%。その枠のRを単純にSRへ変換する方式。SSR個別確率は3%を対象SSRへ配分し、ピックアップ率は個別表で明示。SSRが複数いても合計3%。80回連続SSRなしで次の1回がSSR保証（81回目）。SSR獲得でカウンタ0。保証は同系統常設・限定間で持ち越し、専用コラボは別枠にするなら開始前に明示。製品では履歴と残り回数を常時表示。
1回300無償石、10回3000石。プロトタイプはデモ石を使い、実金銭と無関係。自然抽選ではこの比率と天井を実装し、デバッグ演出確認は石を消費せず結果を所持品に追加しない。

## 確定と昇格
SSR確定予兆は『五つの星が同時に点灯』『金色の第三環』『門の向こうから名前を呼ばれる』。SSR結果でのみ表示。SR保証は紫の第二環。SSRの一部は最初青で進み、接続段階で金へ昇格する。昇格も最初から確定済みで抽選し直さない。外れ結果で確定予兆を流さない。
10連は最大レア度に合わせた共通演出→10枚まとめ表示。SSRだけもう一度人物カットインを再生可能。結果のNEW、重複交換素材、天井進捗を一覧で表示し、受取連打を不要にする。

## 音・振動・見やすさ
接近は低音の持続、接続は金属環、SRは二音上昇、SSRは無音0.2秒→和音→人物台詞。今回の試作はWeb Audioによる合成音のみで、製品用BGM・ボイス・SEは未収録。音・振動は既定で控えめ、個別OFF可能。フラッシュは全白点滅でなく中心部の光量変化にする。演出軽減設定では動く輪・粒子・振動を止め、レア度文字と静止背景で同情報を表示。スキップ後も一覧に保証理由を残す。

## 所持超過・重複
キャラの所持数枠を設けず、重複はキャラIDごとの継承片へ変換する。継承片は別人生素材・外見などに交換。重複限定の能力上限を作らない。結果受領は抽選トランザクション内に含める。演出で「受け取る」を押させない。

## 計測
自然抽選の出現分布、draw_idの二重発行、石負値、天井の境界80/81、10連保証と天井競合、切断後復帰、スキップ直後の結果一覧を検証。演出満足度はSSRだけでなくR/SRのテンポと再生OFF率も測る。
