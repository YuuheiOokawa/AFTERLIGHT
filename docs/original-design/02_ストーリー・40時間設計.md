# ストーリー構成と40時間の制作設計

## 時間の定義
40時間は初回クリアに必要な能動プレイの中央値。テキスト閲覧、移動選択、戦闘、必須育成を含み、通信待ち、スタミナ回復待ち、ログイン間隔は除く。標準速度・初見・一般的な編成を想定。スキップ中心なら短く、探索中心なら長くなる。強制周回で不足時間を埋めない。

|構成|数量×仮平均|時間|
|---|---|---:|
|通常クエスト|144戦×6分|14.4h|
|章内精鋭戦|12戦×12分|2.4h|
|章末ボス|12戦×16分（会話・再編成込み）|3.2h|
|本編会話と選択|12章×40分|8.0h|
|探索と地図修復|12章×30分|6.0h|
|必要育成・装備・チュートリアル|全体360分|6.0h|
|合計|168戦＋非戦闘|40.0h|

各章は14クエスト（通常12、精鋭1、ボス1）。1章3時間20分を基本とするが、導入と終盤の長さを調整する。content/quests.csvは168行のステージ骨子。本文・敵編成・会話・カットシーンの全制作は後続作業。

## 12章の展開
|章|題名／場所|主事件|プレイヤーが行う選択|手がかりと回収|ゲーム導入|
|---|---|---|---|---|---|
|1|まだ降らない雨／未明港|崩れる港からリュカを連れ出す|港の地図を残すか、人々の名前を残すか|地上にも同じ欠落した雨音がある→10章|タップ、敵選択、防御|
|2|勝利のない城／硝子砦|戦争がなかった未来の兵士が消える|武器を地上へ持ち帰るか、門を支える道具に変えるか|ガランの盾は人名ではなく駅名→6章|装備、まとめ強化|
|3|未刊の図書館／逆頁書庫|セナがまだ生まれていない人の伝記を守る|本を保存か、記憶を町へ渡すか|主人公の伝記だけ本文がない→11章|別人生、回復|

|6|止まるための駅／零番線|盾の駅が現れる。英雄の勝利が街を消していた|勝利の記録を残すか、被害の記録を残すか|2章の盾の秘密を回収|予告、ブレイク|

|11|空白の主人公／白紙庭|主人公は誰にも選ばれなかった『仲介』そのもの|自分の人生を固定か、役割を皆へ分けるか|3章の空白伝記を回収|最終別人生|

## テキスト構成と制作量
各章：導入会話8分、道中4会話×4分、精鋭後会話6分、ボス前後10分。1章に主要選択1つ＋任意会話3つ。12選択は個別フラグとして保持し、分岐ツリーを倍々で増やさない。会話に現れる人物・背景・拠点の3レイヤーで差分を合成する。総本文目安9万〜12万日本語文字。会話速度は実測で調整し、文字数から時間を断定しない。

## 第1章冒頭・本文サンプル
雨が降る予定だった。

港の時計台には、そう書かれていた。時刻の代わりに天気の約束を掲げる街を、あなたは初めて見た。傘屋の軒先には開いた傘が並び、その下で人々が空を見上げている。雲はない。それなのに石畳は濡れていた。

「ここでは、起こらなかったことから壊れていく」
白い髪の女が時計台の文字を指でなぞった。雨の一字だけが風にほどける。すると傘屋の奥で、店主の肩が透けた。
「地上の誰かが傘を持たずに出かけた。それだけでこの港の明日はなくなった」

あなたは地図を広げた。海岸線の外に知らない道が一本伸びている。
「全員を連れていく」
女は答えず、地図の余白を見た。
「その紙に、港まで載せられる？」

救うとは持ち帰ることだと思っていた。だが人を連れていけば、その人が暮らした場所はどうなる。あなたは初めて、地図の白い部分を怖いと思った。

[選択] 港の輪郭を描く / 住民の名前を書く
ここでは戦闘能力は変えない。ホーム背景の灯台／名札、リュカの章末台詞、9章の支援NPCが変わる。

## 時間検証
20名の初見テストで章別プレイ時間、会話スキップ率、敗北回数、強化滞在時間を収集。中央値36〜44時間を合格帯とする。長すぎる場合は編成負荷と重複戦闘を減らし、短すぎる場合は新しいギミック・探索・任意サブストーリーを増やす。必須戦闘は全て手動クリア可能で、課金・ガチャ最高レアを要求しない。
