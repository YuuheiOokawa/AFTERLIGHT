# UX・画面仕様

## ナビゲーション
タイトル → ホーム。下部常設タブ：ホーム／クエスト／ユニット／装備／召喚。交流はホームのカードからアクセス。戦闘中は下部タブを隠し誤離脱を防止。設定と所持情報は上部。戻るは前の文脈を維持し、ページ先頭へ毎回リセットしない。

|画面|主操作|表示する情報|完了まで|
|---|---|---|---|
|タイトル|旅を始める|ロゴ、背景、試作版表記|1タップ|
|ホーム|続きから出撃|次クエスト、編成、育成不足、交流|編成確認→開始の2タップ|
|クエスト|章とステージを選択|敵・報酬・難度・クリア状況|通常3タップ|
|バトル|敵指定＋キャラタップ|HP、行動済、必殺、予告、戦況ログ|階層なし|
|ユニット|複数選択、一括強化|所持、属性、レベル、必要素材|選択→確認→確定|
|装備|まとめ強化・装備先|種類、+値、特性、保護、費用|まとめ選択可能|
|召喚|1回/10回|費用、所持、率、天井、対象|確認→演出→一覧|
|ギルド|ノード修復|貢献、週達成、参加状態|一画面|
|フレンド|検索・申請|公開プロフィール、支援|検索→申請|
|アリーナ|練習／出撃|相手編成、正規化説明|候補→確認→開始|
|設定|音、演出軽減、データ初期化|保存状態、試作説明|初期化は確認必須|

## ユニット／装備の一括操作
タップでトグル選択、全選択と解除を並べる。強化後の状態・素材費用のプレビューを表示し確定ボタンは一つ。素材不足は必要/所持を表示、獲得クエストへのリンクを出す。フィルタ・並び順・選択状態は画面移動で保持する。ロック品と装備品は自動素材対象から除外。

## タップ予算
本編再開：ホーム「続きから」→出撃確認「出撃」=2。
章指定：クエストタブ→ステージ→「出撃」=3。
一括強化：ユニットタブ→全選択→一括強化→確認=4。
再挑戦：結果「再挑戦」=1。
召喚：召喚タブ→10連→費用確認=3。
全画面モーダルは一階層に制限、細かい報酬受取モーダルを連続させない。

## 視認性
論理44px以上の主タッチ領域、重要操作48px以上。文字は本文14〜16px、補助12px以上。端末のsafe area、ホームバー、ノッチを避ける。レア度は色＋R/SR/SSR、状態異常はアイコン＋文字、音の情報は文字でも示す。戦闘カードが狭い場合は2段3+2へ配置し、通常攻撃と必殺を別ターゲットにする。

## 動き
UI押下は0.1秒、モーダル0.18秒。重要結果表示を自動で消さない。攻撃は0.3〜0.6秒、必殺1.5〜2.5秒。演出軽減は粒子・回転・振動をOFF。OSのprefers-reduced-motionも拾う。多重モーダル・スクロール背景の誤操作を防ぐ。

## 試作画面の利用
prototype/index.htmlをPCブラウザで開く。assetsフォルダとの相対位置を維持する。スマホでfile://を開けない場合はPC側で同梱launch.batを実行し、同じWi-FiのスマホからPCのLANアドレス:8080/prototype/へアクセスする。ローカルHTTP用。製品サーバー用途で使わない。
試作のギルド・フレンドは画面内ローカル状態であり実プレイヤーと通信しない。アリーナは正規化された模擬バトル。設定で試作データを初期化できる。ローカル保存不能でもそのセッションの操作は続行し、保存できない旨を表示する。
