# v0.2からv0.3への更新

## ローカル
1. 起動中のアプリを止める。
2. 既存の`.local-db/afterlight`と`.env.local`を維持し、ZIPのソースを同じプロジェクトへ配置。
3. `npm ci`を実行。
4. `npm run db:migrate`を実行。DATABASE_URLがない開発環境ではPGlite、設定済みならPostgreSQLへ適用。
5. `npm run dev`で起動。新しいフォルダへ配置した場合は、旧データを維持するためLOCAL_DB_PATHを旧DBの絶対パスに指定する。

フォルダを新規作成し、既定のローカルDBパスを変えた場合は別DBとして新しい旅が始まります。元DBを消す必要はありません。

## Vercel
既存と同じDATABASE_URL・公開ドメインを使用。migrationを適用後にv0.3をDeployする。公開方法はVERCEL_DEPLOY.md。ユーザーのVercel環境への実Deployは未実施。

migration version 2はゲーム状態JSONへ未存在の4項目を追加します。キャラ・装備・通貨・クエスト進捗は維持。再実行しても既存の値を初期化しません。プレイヤーID、ログインID、セッション方式も変更しません。

- ホーム→残響ボス：本編42戦から最初の段階が解放。4段階の解放は42/70/98/126戦。
- ホーム→工房試練：本編14戦から。各課題の武具・編成条件を満たすと出撃可能。
- 武具工房→残響武具：ボス1体以上のクリア、残響片20、金貨6000で製作。

- 出撃確認→支援選択：承認済みフレンドから選ぶ。戦闘中の支援ボタンで1回発動。
