# AFTERLIGHT ― 未明の継承者
Vercel向けNext.js / TypeScriptの縦持ちWeb RPG。v0.3（開発版）。
前回の画面試作から、サーバー権威のゲーム処理・永続保存・認証・非同期交流を持つアプリへ移行したソース一式です。

## v0.3で追加した内容
- 承認済みフレンドの支援を出撃時に選び、戦闘中に1回発動。能力は出撃時に固定し、過度なレベル差を補正。アリーナでは使用しません。
- 24種類の残響ボス。6系統×4段階、HP半分の行動変化、反射・毒・ゲージ削減など。星評価と最短ターンを保存。
- 30の工房試練。武具の+値、役割数、別人生ノード、スキルLvの条件を検査。
- 道中48場面の本文・記録。以前の選択を反映する文章差分、章ごとの絞り込み、初回記録報酬。
- 残響武具：+5で製作。武器ATK+8%、守具DEF+10%、遺物HP+12%の追加刻印。PvPでは数値を正規化。
- 攻撃・必殺・支援の短い演出。既存の連続タップ予約を維持。
- v0.2の保存データを移行。更新手順はdocs/UPDATE_v0.3.md。

## ローカルで遊ぶ
Node.js 22以上を用意し、このフォルダで実行します。

```bash
npm ci
npm run dev
```

`http://localhost:3000` を開く。DATABASE_URLが未設定の開発環境では、PostgreSQL互換のPGliteが`.local-db/afterlight`へ永続保存します。環境設定ファイルがなくても開発モードは起動できます。
タイトルで名前を入力→旅を始める。ゲストもサーバーに保存されます。設定からログインID/パスワードを登録すると、同じDBにつながる別端末で続きを遊べます。未登録ゲストのCookieを消すと復帰できないため、引継ぎ用アカウント登録を用意しています。

## Vercelで配信
詳しい手順は **docs/VERCEL_DEPLOY.md**。

1. このフォルダを非公開GitHubリポジトリへ追加し、VercelへImport。
2. Framework PresetはNext.js、Root Directoryはpackage.jsonのあるフォルダ。
3. PostgreSQLを用意し、Vercelの環境変数`DATABASE_URL`へ接続URLを設定。
4. 同じURLをローカルの`.env.local`に設定して`npm run db:migrate`を実行。
5. VercelでDeploy。ドメインが決まったら`APP_ORIGIN`へそのoriginを設定してRedeploy。
6. `/api/health`が`ready`を返すことを確認。

このZIPはソース納品です。Vercelアカウント・データベースの作成や実デプロイは行っていません。VercelではDATABASE_URLなしのローカル保存に自動退避せず、ゲームAPIは503になります。端末やサーバーレス関数のファイル領域へ本番データを保存しません。

## 実装状況の境界
168ステージは実際に解放・戦闘・クリアできます。ストーリー本文は各章の導入・結末・道中4場面を実装し、全ステージの専用会話・カットシーンを制作した状態ではありません。
本編40時間／エンド500時間は前回からの目標です。本版はその時間量を満たした製品とは表示していません。500時間設計にある季節イベント6本、30人分の別人生会話、残響ボスの追加ルールセット等は未制作。現在の別人生は能力分岐、回廊は章ギミックを組み合わせる戦闘です。24残響ボスと30工房試練は実装済みです。
承認済みフレンドの支援をPvEで借りて使用できます。出撃時の許可・能力を固定するため、その戦闘の途中でフレンド設定が変わっても既に借りた支援は変わりません。PvPは非同期で、リアルタイム通信対戦はありません。レーティングは通算、試合記録に週IDを保持しますが、週リーグへのリセット・順位報酬配布は未実装です。
実金銭購入、メール認証/パスワード再発行、自由入力チャット/通報対応、管理画面、製品用BGM/声優音声、ネイティブAPK/IPAは未実装。ガチャ費用はゲーム内報酬の無償石のみです。
